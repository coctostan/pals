<objective>
## Goal
Ship the Module Efficacy Ledger as a complete, immediately usable feature: an authority contract, a `MODULE-LEDGER.md` template, a UNIFY append step that emits one `Phase | Module | Status | Finding? | Actioned?` row per dispatched module, and a `/paul:config` per-module efficacy read-out — all derived-aid only, workflow-owned writes, human-approved config changes, enforcement-module demotion exemption.

## Purpose
Close the evidence loop identified in the v2.73 milestone rationale: module dispatch evidence already exists in every SUMMARY but is never aggregated, so users run all 18 modules with no visibility into which contribute (field review 2026-07-10: quark + hybrid-energy-reasoner show ARIA/LUKE/GABE/DANA/OMAR/REED/VERA/PETE at ~zero findings across ~450 phases — anecdotal until the ledger makes it measurable). Phase 306 makes efficacy measurable on every project going forward and gives Phase 307's retroactive harvest a fixed target format.
